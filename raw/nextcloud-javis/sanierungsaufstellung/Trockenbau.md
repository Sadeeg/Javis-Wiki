# 3. TROCKENBAU

**Warum diese Änderungen?**

Die Trockenbauwände waren im ursprünglichen Sanierungsfahrplan **nicht in diesem Umfang** geplant. Sie wurden durch die Umstellung auf Fußbodenheizung notwendig:

1. **Vorgesetzte Wände für Elektrik:** Bei einer Fußbodenheizung kann die Elektrik nicht mehr in den Wänden verlegt werden (Estrich wird darunter gegossen). Deshalb wurden im Wohnzimmer, Esszimmer und Gang separate Trockenbauwände zur Kabelverlegung errichtet.

2. **Heizkreisverteiler-Verkleidung:** Der Heizkreisverteiler muss in einer Trockenbauwand versteckt werden – im ursprüngigen Plan war kein Platz dafür vorgesehen.

3. **Kernbohrung verbergen:** Die Kernbohrung für die Elektrik-Durchführung wurde mit einer Vorsatzwand im 1.OG Gang kaschiert.

4. **Zukünftige Dusche im EG:** Die Trennwand zum WC wurde so geplant, dass eine spätere Dusche möglich wäre – bei fertiger Fußbodenheizung wäre dies nicht mehr machbar.
